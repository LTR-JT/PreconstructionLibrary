Preconstruction Library 15.18.2

Requires Bladesong Mod Framework 0.1.4 or later and compatible UE4SS.

- The framework now owns the Creative screen, folder tabs, footer and multi-delete controls.
- PCL supplies its Parts/Blades library content and actions through the shared menu.
- Existing library and save locations are retained.
- Parts selects Hilt mode; Blades selects Blade mode in the Forge.

Use Runtime.zip for manual installation or install from Mods > Browse after framework setup. The BMF.zip is the in-game install package.
